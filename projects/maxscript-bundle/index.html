Maxscript May Bundle

Tags: Scripted tool, utility scripts Software: 3DSMax, Maxscript

The Problem

During my teaching role, I would be asked to help fix common issues for mesh geometry such as pivot points, remove ngons and more. During May I setup a challenge to learn some Maxscripting so I could create a series of tools that students can use to tackle their problems.

How I Made It

These tools all use Maxscript and interface directly with 3DSMax using easy drag and drop.

3DSMax 2026 the Pivot Tool is known to break on initial dropin, redrag to fix.
In the future I want to replace these all these scripts with one primary Python variant.

Checkout my Full Development Blog Post

Final Outcomes

The repo contains:

  • Batch Mesh Renamer
  • Pivot Setter Tool
  • Mesh Validator (identifies ngons and poor geometry faces)
  • Location Setter (for exporting and setting up asset zoos)
  • Tree Generator (fun stylised tree maker entirely written in Maxscript!)
