House Generator Tool

Tags: Procedural Mesh, HLSL
Software: Houdini, Unreal Engine Project Total Time: 5 weeks total (off and on part time)

This project page is still being constructed.

The Problem

Building variant houses and large strucures can take a lot of time to setup and even further time to change out pieces or randomise values to make the building standout from those around it. I needed a building tool as I was preparing a large modular kit, the tool needed to be able to handle a adjustable kit and provide a lot of customizability for internal values on shaders.

How I Made It

To create this tool I used Houdini for its logic of procedural placing actors alongside creating a blockout to better visualise the size and shape of the building before actors as spawned. For running the tool I used Unreal Engine to see how well it performs real-time as a artist adjusts it. Checkout my Development Blog Post
